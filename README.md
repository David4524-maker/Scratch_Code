# Scratch Code

Scratch Code es lo que pasa si mezclas Scratch + Código y además tiene su propio formato **.sc**

## Caracteristicas

- 6 idiomas

- Bloques

- Formato **.sc**

- Editor de píxeles

- Multiplataforma (Windows, macOS, Linux)

## Requisitos

| Requisito | Detalle |
|---|---|
| **Python** | 3.10 o superior (probado en 3.14) |
| **Tkinter** | Incluido en la instalación estándar de Python |
| **Dependencias** | Ninguna |
| **Sistema operativo** | Windows, macOS o Linux |

> **Nota para Windows:** si al ejecutar aparece un error de Tkinter, vuelve a ejecutar el instalador de Python y marca la casilla **"tcl/tk and IDLE"**. No es un paquete externo, es un componente del propio Python
